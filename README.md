# 饥荒联机版 - 增强手柄控制 Mod

[English](README_EN.md) | 简体中文

一个强大的饥荒联机版（Don't Starve Together）手柄增强 Mod，提供自定义按键组合、虚拟光标、地图自动寻路、游戏内配置界面等功能。

## ✨ 核心功能

### 🌟 功能亮点

- 🎮 **12种自定义按键组合** - 完全可配置的手柄按键映射
- 🖱️ **虚拟光标系统** - 手柄模拟鼠标操作，全屏交互
- 🧰 **自动建造系统** - 自动搜索附近材料、容器并制作次级材料
- 🍲 **菜谱书搜索烹饪** - 从原生菜谱详情搜索附近食材与空闲锅具并自动开火
- 📋 **ActionQueue 适配** - 在虚拟光标中使用手柄框选并启动行为队列
- 🗺️ **地图自动寻路** - 点击地图自动导航，智能路径规划
- 📍 **玩家位置与收藏点** - 手动查询玩家快照、收藏当前位置并从面板导航
- 🕳️ **虫洞追踪** - 自动记录虫洞配对，地图显示编号
- ⚙️ **游戏内配置** - 无需重启，实时调整所有设置
- 🌍 **多语言支持** - 中文/英文自动切换
- 🎯 **智能目标选择** - 主/副/检查三重目标系统
- 📐 **增强视角控制** - 平滑缩放和旋转

### 🎮 自定义按键组合

支持 **12 种按键组合**，每个组合可配置按下和释放时的动作：

- **LB + A/B/X/Y/LT/RT**
- **RB + A/B/X/Y/LT/RT**

每个组合支持：
- 按下时执行动作 (`on_press`)
- 释放时执行动作 (`on_release`)
- 动作序列（可连续执行多个动作）

### 🖱️ 虚拟光标系统

使用手柄右摇杆控制鼠标光标，实现完整的鼠标模式操作：

**功能特性**：
- ✅ 右摇杆控制光标移动（全屏范围）
- ✅ LT 按键 = 鼠标左键
- ✅ RT 按键 = 鼠标右键
- ✅ 支持悬停检测和实体高亮
- ✅ 支持拖拽行走（8帧检测阈值）
- ✅ 支持点击 UI 元素（物品栏、制作菜单等）
- ✅ 世界实体与 UI 控件磁吸，范围和优先级可配置
- ✅ 世界实体使用实际鼠标命中区域中心，动画变化不会造成吸附抖动
- ✅ 无额外 Mod 死区，非线性响应曲线兼顾微调和满推速度
- ✅ 可配置光标速度（0.5x - 2.0x）
- ✅ 可显示/隐藏光标图标

**默认切换按键**: LB + RB + RT（同时按下）

### 🧰 自动建造系统

当背包材料不足时，制作菜单和 `craft_item` 动作可以启动经过校验的自动建造流程：

- 在动作编辑器中按中文名、英文名或内部配方名搜索
- 动态读取当前有效配方，包含角色、活动及其他 Mod 添加的配方
- 搜索玩家附近 6 单位内的地面材料和可安全打开的储物容器
- 按世界/洞穴分片缓存已查看容器的内容，并在使用前重新验证
- 优先使用已有次级材料；不足时自动规划并制作中间材料
- 背包满时只会临时放下可安全恢复、且不属于配方需求的普通物品
- 建筑配方完成取材后直接进入原生放置模式
- 任意手动控制、死亡、动作失败或材料变化都会中断；已发生的取材/制作不会回滚
- 如果开工前背包中没有某种外部材料，完成后该类型的剩余整组会丢回地面；开工前已有则不自动丢弃

制作菜单会把可由附近材料完成的配方标记为“自动建造”。点击后 Mod 会先关闭菜单、逐个验证容器，再执行计划。

### 🍲 搜索烹饪

按键配置中的“打开菜谱书”会直接打开游戏原生菜谱，不要求背包中持有菜谱书物品。对已解锁且有有效四格配方的料理，详情页会显示“搜索并烹饪”：

- 搜索附近的普通锅、远古锅和便携烹饪锅，并只使用空闲的空锅
- 从随身物品、地面和经过验证的附近容器取材，逐格校验后调用原生烹饪按钮
- 与自动建造共用搜索半径、智能/完整搜索模式和容器数量限制
- 任意手动控制或环境变化都会安全中断

### 📋 ActionQueue 手柄适配

安装 ActionQueue RB3 后，在设置中启用“ActionQueue 手柄适配”，并开启虚拟光标：

- **按住 RB + LT 拖动**：左键框选/加入队列
- **按住 RB + RT 拖动**：右键框选/加入队列
- **RB + B**：取消当前选择和行为队列

框选期间会临时关闭光标磁吸；物品栏、地图和其他 UI 不会触发世界框选。

### 🎯 多目标选择系统

智能目标选择，支持三种独立目标：

1. **主目标** (`controller_target`) - A键交互
   - 支持主动作的实体

2. **副目标** (`controller_alternative_target`) - B键交互
   - 只有副动作的实体
   - 主目标有副动作时自动清除

3. **检查目标** (`controller_examine_target`) - Y键检查
   - 只能检查的实体（如装饰品）
   - 主目标和副目标可检查时自动清除

**目标选择特性**：
- 独立评分系统
- 支持 360° 选择或前向选择
- 距离和角度权重计算
- 不可穿透实体优先

### ⚙️ 游戏内配置界面

按 **Ctrl+K**（键盘）或 **LB+RB+Y**（手柄）打开配置界面：

**功能**：
- 🎨 3层界面：主界面 → 详情界面 → 动作编辑器
- 🎮 完整手柄支持（A/B 选择/取消，LB/RB 切换标签）
- 💾 实时保存配置
- 🔄 即时生效（无需重启）
- 🎯 两个标签页：
  - **按键配置**: 配置 12 种按键组合
  - **Mod 设置**: 调整攻击角度、交互角度、强制攻击模式、虚拟光标设置

### 📐 视角控制增强

- **LB + 右摇杆左右**: 旋转视角
- **LB + 右摇杆上下**: 缩放视角
- Mod 运行时统一使用控制方案二，无需用户手动修改游戏设置；不会主动写入用户存档
- 可配置旋转和缩放速度

### 🗺️ 地图自动寻路

在地图界面使用虚拟光标快速导航到目标位置：

**功能特性**：
- ✅ 虚拟光标点击地图开启自动寻路
- ✅ A* 算法与地形代价感知的智能路径规划
- ✅ 直线路线与道路绕行按预计耗时比较，选择至少快 2% 的路线
- ✅ 地形感知代价系统
- ✅ 实时路径可视化（地图上显示路径点）
- ✅ 手动移动自动取消寻路
- ✅ 障碍物自动绕行

**地形代价系统**：
| 地形 | 速度修正 | 路径代价 |
|------|----------|----------|
| 道路/卵石路 | +30% | 0.77 (优先) |
| 普通地面 | 0% | 1.0 |
| 岩石/沼泽 | 0% | 1.2-1.5 |
| 地陷 | -70% | 3.33 (避开) |
| 蜘蛛网 | -40% + 攻击风险 | 5.0 (强烈避开) |

**使用方法**：
1. 按 `M` 键打开地图
2. 按 `LB+RB+RT` 开启虚拟光标模式
3. 使用右摇杆移动光标到目标位置
4. 按 `RT`（鼠标左键）点击地图
5. 关闭地图，角色将自动寻路到目标位置

**地图控制**：
- **左摇杆**: 平移地图
- **LB + 右摇杆垂直**: 缩放地图
- **LB + 右摇杆水平**: 旋转视角
- **RT**: 点击地图设置寻路目标
- **RB**: 右键点击（取消/其他操作）

**玩家位置与收藏点**：
- 位置窗口默认打开“玩家位置”页；每次进入会清除旧玩家标记
- 点击玩家名字会先查询其最新位置，收到回复后自动开始寻路；也可查询全部玩家
- 安装本 Mod 的玩家收到查询后会自动回复一次位置，地表与洞穴分开显示
- 地图只显示其他玩家的位置和收藏点，不显示自己的位置
- “收藏当前位置”可命名、重命名和删除，按世界与分片持久化保存
- 位置查询使用可读的世界聊天文本传输；未安装本 Mod 的玩家可能看到这些消息

### 🕳️ 虫洞追踪系统

自动记录虫洞配对关系，无需手动标记！

**功能特性**：
- ✅ 自动记录：使用虫洞时自动记录进入/退出位置
- ✅ 配对识别：自动识别哪两个虫洞是一对
- ✅ 地图显示：在地图上显示配对编号（相同数字 = 一对）
- ✅ 持久保存：数据保存到本地，每个世界独立存储
- ✅ 联机支持：在联机服务器中正常工作

**使用方法**：
1. 正常使用虫洞（跳进去）
2. 系统自动记录该虫洞与出口虫洞的配对关系
3. 打开地图，已探索的虫洞对会显示相同的数字编号
4. 下次看到地图上的数字，就知道哪两个虫洞是一对了！

**存储位置**：
`client_save/wormhole_pairs_[world_id].json`

## 🎬 可用动作

### 战斗类
- **attack**: 攻击目标
- **force_attack**: 强制攻击（忽略友军）

### 检查类
- **examine**: 检查目标
- **inspect_self**: 检查自己

### 装备类
- **equip_item**: 搜索并装备指定物品（支持中文名、英文名和 prefab）
- **cycle_head**: 循环切换头部装备
- **cycle_hand**: 循环切换手部装备
- **cycle_body**: 循环切换身体装备

### 物品类
- **use_item_on_self**: 搜索物品并对自己使用（支持中文名、英文名和 prefab）
- **use_item_on_scene**: 搜索物品并对场景/目标使用（支持中文名、英文名和 prefab）
- **use_active_item_on_self**: 对自己使用光标选中的物品
- **use_active_item_on_scene**: 对场景使用光标选中的物品
- **save_hand_item**: 保存手持物品到缓存
- **restore_hand_item**: 恢复缓存的物品到手上

### 制作类
- **craft_item**: 自动搜索附近材料和容器，制作指定物品；动作序列会等待其完成或中断
- **toggle_cooking_menu**: 打开原生菜谱书（保留旧动作 ID 以兼容已保存配置）

### 系统类
- **trigger_key**: 触发键盘按键
- **enable_virtual_cursor**: 启用虚拟光标
- **disable_virtual_cursor**: 禁用虚拟光标

### ⏱️ 自动延迟系统

装备/物品使用动作会自动在下一个动作前等待 **0.3 秒**，确保联机模式下状态同步。

**自动延迟的动作**：
- 装备类：`equip_item`, `unequip_item`, `cycle_*`, `swap_*_last`, `restore_*_item`
- 使用类：`use_item_on_self`, `use_item_on_scene`, `use_active_item_*`, `use_equip`

**示例配置**（无需手动添加 delay）：
```
on_press: save_hand_item → equip_item(lighter) → use_item_on_scene(lighter)
on_release: use_item_on_scene(lighter) → restore_hand_item
```
系统会自动在 `equip_item` 和 `use_item_on_scene` 之间添加 0.3 秒延迟。

## 🐛 常见问题

**Q: 虚拟光标模式下无法选择物品栏？**
A: 虚拟光标模式会自动清除物品栏选择，直接用光标点击物品栏即可。

**Q: 配置界面无法打开？**
A: 确保不在其他菜单界面中，按 `Ctrl+K` 或 `LB+RB+Y`。

**Q: 按键组合没反应？**
A: 检查配置界面是否正确设置了动作，确保同时按下组合键。

**Q: 如何恢复默认配置？**
A: 删除 `client_save/enhanced_controller_config.json`，重启游戏。

**Q: 游戏卡顿？**
A: 尝试降低虚拟光标速度或关闭光标显示。

**Q: 自动寻路不工作？**
A: 确保在地图界面开启虚拟光标后点击有效的地面位置。如果路径被障碍物完全阻挡，寻路会失败。

**Q: 寻路中途停止？**
A: 任何手动移动操作（摇杆输入）都会自动取消寻路。这是防止冲突的设计。

**Q: 地图上看不到路径？**
A: 路径可视化只在地图打开时显示。关闭地图后角色会按照已规划的路径行走，但不再显示路径点。
